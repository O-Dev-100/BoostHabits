🚀 **BoostHabits - Habit Tracker Gamificado**

Aplicación Android para la gestión de hábitos con mecánicas de RPG y gamificación.


✨ **Características Principales**

- 🛠 **Arquitectura MVVM**: Código limpio y mantenible.
- 📉 **Health Connect**: Sincronización real con pasos y actividad física.
- ☁️ **Firebase**: Datos sincronizados en la nube en tiempo real.
- 🎨 **Personalización Dinámica**: Sistema de temas, fondos y cosméticos desbloqueables.
- 🌍 **Multi-idioma**: Soporte completo para Español e Inglés.

🛠 **Tecnologías**

- **Kotlin** & **Jetpack Compose / XML Layouts**
- **Room Database** (Persistencia local)
- **WorkManager** (Tareas de fondo)
- **Firebase Auth & Firestore**
